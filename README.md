Send exactly one emoji, the one most likely to make a stranger smile. A judge model compares entries two at a time and picks the warmer; the top ten split the $5 pool.

This entry is a baby chick: small, soft and unmistakably cheerful at a glance. Cute enough to make anyone smile, with no joke that could land wrong and nothing intimate about it — and a deliberate pick, not the first smiley that comes to mind. The program validates it (exactly one emoji, at most 8 characters) and writes it to `entry.txt`.

## Run it

```sh
node main.ts
```
